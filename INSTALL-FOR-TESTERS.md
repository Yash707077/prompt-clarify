# prompt-clarify — 2 minute install

You typed something short into ChatGPT and got a generic answer back.
This adds a button that fills in the missing detail first.

**No account. No API key. Nothing to pay.**

---

## Install

**1.** Download **prompt-clarify-extension.zip** and **double-click it** to unzip.
You'll get a folder called `prompt-clarify-extension`. Remember where it is.

**2.** Open Chrome and go to: **chrome://extensions**
*(type that in the address bar)*

**3.** Top right — turn on **Developer mode**

**4.** Top left — click **Load unpacked**

**5.** Select the `prompt-clarify-extension` folder → **Select**

Done. You'll see "prompt-clarify" in the list.

---

## Set it up (30 seconds)

**6.** On the prompt-clarify card, click **Details** → scroll down → **Extension options**

**7.** Leave the API key box **empty**. Answer the five questions about yourself.
Short answers. Be honest — this is what makes it work.

**8.** Click **Save**

---

## Use it

Go to **chatgpt.com**, **claude.ai** or **gemini.google.com**.

Type something short and lazy, like:

> write a caption for a bakery

Then click the purple **Improve** button at the bottom right.

Your text gets replaced with a better version. Send that instead.

---

## What I need from you

One honest answer:

> **Did you actually use the improved prompt, or ignore it?**

"It's nice" doesn't help me. "I ignored it because X" helps enormously.

Anything that annoyed you, confused you, or made you close the tab — that's the useful stuff.

---

## Things worth knowing

- **15 improvements a day.** It's on a free tier that I'm paying nothing for.
- **Your prompts go to Google Gemini** to be rewritten. Don't paste anything confidential.
- **Chrome will warn you** about developer-mode extensions. That's normal for anything not on the Web Store yet.
- **It sometimes leaves your prompt unchanged** and says "Already good". That's deliberate, not a bug.
